> **Experience the Flow**: A portfolio that explores the intersection of high-performance engineering and fluid interactive design.

## 🚀 Overview

This portfolio showcases my work as a **Full-Stack Developer** with a focus on scalable architecture and premium user experiences. It features a custom **"Thread" navigation system** that physically connects sections as you scroll, utilizing complex mathematical synchronizations between DOM elements and WebGL contexts.

## ✨ Key Features

- **🧵 The Thread**: A continuous, physics-simulated line that traverses the application, glowing when interacting with tech stacks and projects. Synchronized via **GSAP ScrollTrigger**.
- **🌌 Three.js Background**: A highly optimized, full-screen particle starfield shader implemented with **React Three Fiber**.
- **⚡ Performance First**:
  - Lazy-loaded 3D assets.
  - Native scroll handling for lightweight interaction.
  - Component-level code splitting.
- **🎨 Design System**: Built with **Tailwind CSS**, featuring glassmorphism, dynamic gradients, and sophisticated micro-interactions.

## 🛠 Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Animation**: GSAP (GreenSock), Framer Motion patterns
- **3D / WebGL**: Three.js, React Three Fiber, Maath
- **Styling**: Tailwind CSS
- **Code Quality**: ESLint, Prettier

## 📦 Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/saintell/portfolio.git
   ```

2. **Install dependencies**:
   ```bash
   cd portfolio
   npm install
   ```

3. **Run locally**:
   ```bash
   npm run dev
   ```

## 🏗 Project Structure

The project follows a clean, scalable architecture:

```
src/
├── components/   # UI Components (Hero, Navbar, TechStack...)
├── hooks/        # Custom React Hooks
├── utils/        # Logic helpers (Tick throttling, Math intersections)
├── constants.ts  # Content and configuration
├── types.ts      # TypeScript definitions
└── App.tsx       # Main entry point & Context providers
```
